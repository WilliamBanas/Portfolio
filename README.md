# Portfolio

Portfolio personnel d'William Banas, développé avec Next.js, React, TypeScript et Tailwind CSS.

## Démarrage

```bash
npm install
npm run dev
```

Le site est disponible sur [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — serveur de développement
- `npm run build` — build de production
- `npm run start` — serveur de production
- `npm run lint` — ESLint

## Structure

- `src/app` — App Router (layout, page, styles globaux)
- `src/components` — sections et composants
- `src/data` — contenu du portfolio
- `public` — assets statiques
